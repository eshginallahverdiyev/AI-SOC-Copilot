# Changelog

## 1.0.0 - 2026-10-15

Initial public release.

- Combined n8n workflow with two pipelines: Phishing & Attachment Analysis and Wazuh Alert Triage.
- Threat-intelligence enrichment with VirusTotal, URLScan, AbuseIPDB and MalwareBazaar.
- Gemini analysis with structured JSON output and prompt-injection hardening.
- Deterministic guard rails and fail-safe reporting for Wazuh alerts.
- Alert de-duplication, retries and HTML-escaped, defanged reports.
- Sample Wazuh alerts and e-mails, replay scripts, Wazuh integration snippet, Docker Compose file.
- Documentation, generated prompt reference, validation / secret-scan tooling and CI.
